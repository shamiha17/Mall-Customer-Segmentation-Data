# Mall Customer Segmentation Data

## Project Description
A machine learning project focused on customer segmentation using customer demographics and spending patterns from a retail mall dataset.

## Dataset
- Source*: Mall Customers Dataset (Kaggle)
- **Records**: 200 customers
- **Features**:
  - CustomerID: Unique customer identifier
  - Gender: Male/Female
  - Age: Customer age (18-70 years)
  - Annual Income: In thousands of dollars ($15k-$137k)
  - Spending Score: Quantitative score assigned (1-100)

## Features
- Data preprocessing and exploratory analysis
- Feature scaling with StandardScaler
- One-Hot Encoding for categorical variables (Gender)
- Dimensionality reduction using PCA
- Multiple machine learning models:
  - Linear Regression
  - Random Forest Regressor
  - XGBoost Regressor
- Model evaluation and comparison
